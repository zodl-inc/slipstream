# Contributing to ZODL Slipstream

Thank you for your interest in ZODL Slipstream.

## External contributions

ZODL Slipstream is developed internally by the Zcash Open Development Lab
(ZODL) team, and **we are not accepting external code contributions at
this time.** Pull requests from outside the ZODL team will be closed
without review. This policy exists to keep the copyright in ZODL Slipstream
undivided, which is what allows us to offer it under both the AGPL and
commercial terms.

If this policy changes, accepted contributions will require a signed
Contributor License Agreement assigning or broadly licensing the
contribution to Znewco, Inc. before any code is merged. No contribution
of any size, including typo and documentation fixes, will be merged
without one.

## Bug reports and feature requests

Issues are welcome. Please report bugs, performance findings, and
feature requests through this repository's issue tracker. Security
issues should not be filed publicly; see `SECURITY.md` for our
disclosure process.

## Licensing questions

For questions about using ZODL Slipstream under the AGPL, or about
commercial licensing, see `COMMERCIAL-LICENSE.md`.
